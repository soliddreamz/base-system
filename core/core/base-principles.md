# Base System — Core Principles

Base is a creator-owned application system.
It is designed to give creators control, clarity, and independence.

---

## 1. Creator First
Creators are the primary stakeholders.
Platforms, algorithms, and advertisers are secondary.

Base does not require:
- Algorithmic reach
- Forced advertisements
- Platform dependency

---

## 2. Structure Over Style
Base enforces structure, not aesthetics.

Creators may customize:
- Colors
- Media
- Branding
- Content

Creators may NOT alter:
- Core navigation rules
- System behavior
- Locked UI components

---

## 3. Ownership & Portability
All Base apps are portable.
Creators retain ownership of:
- Their content
- Their audience
- Their distribution

Base does not trap creators in closed ecosystems.

---

## 4. Minimal Surface Area
Base avoids unnecessary features.

Every feature must:
- Serve the creator
- Reduce dependency
- Increase clarity

If a feature does not do this, it does not belong in Base.

---

## 5. Quiet Infrastructure
Base operates quietly in the background.

The system is present,
but never louder than the creator.

---

## 6. Respect for Culture
Base is designed to support culture,
not extract from it.

Culture is not a data source.
Culture is the product.
