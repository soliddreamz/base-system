# Base System — UI & Behavior Constraints

This document defines the non-negotiable UI and behavior rules
for all applications built on Base.

---

## 1. Locked Navigation Model
Base applications use a fixed navigation structure.

Rules:
- Navigation location is consistent across apps
- Navigation order cannot be altered
- Navigation behavior cannot be overridden

Creators may rename labels,
but may not change structure or flow.

---

## 2. Locked UI Components
Base provides a predefined set of UI components.

Examples:
- Button
- Card
- List
- Row
- Section

Rules:
- Components may be styled
- Components may not be structurally altered
- No custom components may replace Base components

---

## 3. No Algorithmic Feeds
Base does not allow:
- Infinite scroll feeds
- Algorithmic ranking
- Engagement-based manipulation

Content order is explicit and intentional.

---

## 4. No Forced Advertising
Base does not enforce:
- Platform ads
- Third-party tracking
- Engagement extraction

Monetization decisions belong to the creator,
not the platform.

---

## 5. Consistent System Behavior
Base behavior is predictable.

Rules:
- Back navigation is consistent
- External links return cleanly
- No hidden redirects
- No dark patterns

---

## 6. Accessibility Baseline
Base enforces minimum accessibility standards.

Includes:
- Readable text contrast
- Tap-safe targets
- Predictable layout

---

## Status
This document is LOCKED.
Violations disqualify an app from being considered “Base-compatible”.
